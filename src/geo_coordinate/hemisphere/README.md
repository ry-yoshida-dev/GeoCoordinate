# hemisphere

## Overview

Enums of the `N` / `S` and `E` / `W` letters that sources such as Exif and NMEA
store next to unsigned latitudes and longitudes.

## Components

| Component | Description |
|-----------|-------------|
| [latitude.py](./latitude.py) | `LatitudeHemisphere` enum (`NORTH` / `SOUTH`) of the `N` / `S` abbreviation |
| [longitude.py](./longitude.py) | `LongitudeHemisphere` enum (`EAST` / `WEST`) of the `E` / `W` abbreviation |
